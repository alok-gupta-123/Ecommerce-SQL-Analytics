# E-Commerce Sales & Customer Analytics

## Project Overview

This project analyzes e-commerce sales and customer data
using MySQL.

The objective is to understand sales performance,
customer behavior and product performance.

## Database Tables

- Customers
- Products
- Orders
- Order_Items

## Analysis Performed

- Total revenue
- Revenue by category
- Top-selling products
- Top customers
- Average Order Value
- Cancellation rate
- Monthly revenue
- Repeat customers
- Customer ranking

## SQL Concepts Used

- SELECT
- WHERE
- JOIN
- GROUP BY
- HAVING
- Aggregate Functions
- CTEs
- Subqueries
- Window Functions
- Date Functions

## Tools Used

- MySQL
- MySQL Workbench
- GitHub
